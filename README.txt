LUNCH, DECIDED — LOCAL + CLOUDFLARE PAGES

For Cloudflare Pages settings and project details, see README.md.

Run locally (Windows): open a terminal in this folder and run `python server.py` (or `py server.py`), then visit http://localhost:8000.

Edit data/dishes.txt to change the menu. Put one dish per line; blank lines and lines starting with # are ignored. Locally, refresh the page after saving. On Cloudflare Pages, commit and push the change to GitHub so Pages can rebuild and redeploy.
